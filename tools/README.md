# Third-party tools

## RePKG

[`RePKG`](https://github.com/notscuffed/repkg) (MIT) unpacks Wallpaper Engine `scene.pkg` and converts `.tex` to images.

- Binary: `tools/RePKG.exe` (from [v0.2.2-alpha](https://github.com/notscuffed/repkg/releases/download/v0.2.2-alpha/RePKG.zip))
- Used automatically when you apply a WE **scene** workshop folder

Not affiliated with Wallpaper Engine / Steam / Valve.
